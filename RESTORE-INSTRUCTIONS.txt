استرجاع نسخة الموقع قبل تعديلات التصميم الأخيرة

هذه الحزمة مأخوذة من النسخة الاحتياطية التي رفعتها أنت.
مهم: لا تحتوي على مجلد .git عمدًا، حتى يبقى Git الحالي في مشروعك.

الطريقة:
1) افتح مجلد مشروع musa3d الحالي.
2) لا تحذف مجلد .git.
3) انسخ جميع ملفات هذه الحزمة إلى مجلد musa3d الحالي واختر Replace All.
4) نفّذ:
   git status
   git add -A
   git commit -m "Restore previous website version"
   git push

الملفات الإضافية التي أُنشئت في التجارب الأخيرة يمكن أن تبقى؛ لن تؤثر ما دام index.html/styles.css/app.js/vercel.json القديمة قد عادت.
إذا أردت تنظيفها لاحقًا يمكن حذف الملفات غير المستخدمة بعد التأكد من الموقع.
